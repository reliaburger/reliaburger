# Lines of code: Reliaburger against the Kubernetes stack it replaces

10 November 2026. How much code you run is part of how much code someone can
attack, and how much code anyone can check. This record counts Reliaburger and
the Kubernetes projects that cover the same features, with one tool and one
set of rules for both sides, so the whitepaper's design goal
([§2](../whitepaper.md#trust-from-scrutiny-not-popularity)) can quote a measured
ratio instead of a guess.

**Result: the Kubernetes stack that covers Reliaburger's features is about
10.5 times as much code: 2,134,280 lines of Go against 202,730 lines of Rust,
counted the same way.** Leave out the two projects that do the most beyond
what Reliaburger does (Cilium, and Grafana's backend) and it's still 6.7
times. These are code lines, not bugs, and the caveats below matter.

## Method

The tool is [scc](https://github.com/boyter/scc) 4.1.0 (Homebrew), on both sides.
It counts *code* lines: not blank, not comment. For every project:

- **The main language only:** Go for the Kubernetes projects, Rust for
  Reliaburger. Other languages are listed separately below.
- **Tests out.** Go: `*_test.go`, and directories named `test`, `tests`,
  `testdata`, `testing`, `testutil`, `e2e` or `e2e_node`. Rust: Reliaburger's
  `src/` copied without its test code, by the rules `make loc` uses (a file's
  tail from a column-0 `#[cfg(test)]`, and every file declared as
  `#[cfg(test)] mod name;`), and without `src/fuzz/`, which compiles only for
  tests and the fuzzer. `tests/` is outside `src/` and isn't counted.
- **Vendored code out:** directories named `vendor` or `third_party`.
- **Generated code out where it says so:** `zz_generated*`, `*.pb.go`,
  `*.pb.gw.go`, and any file whose head carries scc's default generated
  markers ("do not edit", `<auto-generated />`), through `--no-gen`.
- **Docs, examples and tooling out:** directories named `docs`, `doc`,
  `examples`, `example` or `hack`.

The command, for each project directory:

```sh
scc --format json --no-gen \
  --exclude-dir vendor,third_party,test,tests,testdata,testing,testutil,e2e,e2e_node,docs,doc,examples,example,hack,.git \
  -M '(_test\.go$|zz_generated|\.pb\.go$|\.pb\.gw\.go$)' DIR
```

"Raw" is scc's code lines for every file of the main language in the
repository, with nothing excluded. Dependencies are read from each project's
root `go.mod`: direct means a `require` line without `// indirect`, total
means every `require` line. Since Go 1.17 `go.mod` lists every module the
build needs, so total is close to Reliaburger's 521 crate versions from
`cargo tree -e normal --target x86_64-unknown-linux-gnu` (66 direct).

**Ratios.** Like-for-like, 2,134,280 / 202,730 = **10.5**. Without Cilium and
Grafana's backend, 1,351,482 / 202,730 = **6.7**. Raw, 22,448,429 / 412,151 =
54.5, but that number mostly measures vendoring: the Go repositories commit
their dependencies' source (Loki's `vendor/` alone is most of its 9.6 million),
and Reliaburger's crates live outside the repository. Quote the like-for-like
ratio, not the raw one.

Other languages, not in the totals: Grafana's frontend is 1,272,680 lines of
TypeScript, Prometheus's 41,608 and Argo CD's 37,961; Cilium's eBPF programs
are 27,050 lines of C and headers. Reliaburger's eBPF programs (`ebpf/`) are
496 lines of C and headers, and its dashboard's built assets (`brioche/`) 400
lines of JavaScript and CSS.

## Caveats

- **Lines aren't bugs.** Code size is a rough proxy for attack surface, and
  Go is wordier than Rust (every `if err != nil`), so some of the ratio is
  the language. The evidence the design goal leans on is narrower: most
  vulnerabilities are in new code, and memory-safe languages have far fewer
  memory-safety bugs per line ([Google](https://security.googleblog.com/2025/11/rust-in-android-move-fast-fix-things.html)).
- **The Kubernetes side does more.** Kubernetes carries cloud-provider
  integration, kubeadm, CSI and much more API; cert-manager speaks ACME, which
  Reliaburger plans for 0.4.0; Cilium does network policy, encryption, load
  balancing and observability that Onion doesn't; Grafana is a general
  dashboard tool. The 6.7 ratio is there for that reason, and it still leaves
  Kubernetes's extra API in.
- **The Reliaburger side does more too, and is counted whole:** Smoker fault
  injection, the batch scheduler, self-upgrade, the TUI, the agent tools, the
  Kubernetes importer and `relish test` and `bench` are all in the 202,730,
  with no Kubernetes project counted against them.
- **Directory-name rules are blunt.** Excluding every directory called
  `testing` drops some fakes that ship in Kubernetes's client libraries, and
  `--no-gen` drops only generated files that say so. Both cut the Kubernetes
  count, not Reliaburger's.
- **One day, one tag each.** Re-run the commands above before quoting the
  numbers again. The scripts are in [`scripts/loc_compare/`](../../scripts/loc_compare/):
  `fetch.py` downloads each tag, `strip_tests.py` removes Rust's `#[cfg(test)]`
  tails by `make loc`'s rules, and `count.py` runs scc with the rules above.
