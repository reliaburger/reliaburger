## Known issues shipped in 0.2.0

- The quickstart pins Lima 2.1.0. Before 2.1.3, any user in a QEMU-driven VM
  (the Linux quickstart) can reach the guest agent's socket and become root in
  the VM (CVE-2026-53657), and the gRPC port forwarder leaks a socket per
  forwarded connection, so a long-running quickstart's API node slowly loses
  memory. Both are fixed by bundling Lima 2.2.1 in 0.2.1
  ([#983](https://github.com/reliaburger/reliaburger/issues/983)). The V02
  tiers and the jobs fast tier ran on the default gRPC forwarder; the jobs
  final's run 2 ran with `LIMA_SSH_PORT_FORWARDER=true`
  ([#986](https://github.com/reliaburger/reliaburger/pull/986)), so it shows
  Reliaburger under 12 hours of job load, not Lima 2.1's forwarder.
- Bun has the default OOM score, so it is the kernel's first choice on a
  memory-starved node ([#984](https://github.com/reliaburger/reliaburger/issues/984), 0.2.1).
