Producer release/stale-report protection, durable consumer recovery and receipt
retry are implemented. Rootless cluster support is explicitly deferred: surviving
execution intent alone cannot authorise reuse of an old remotely published host
port after restart. Container clusters use rootful Linux Runc/eBPF; rootless Runc
is standalone only, and Bun enforces that boundary before ownership recovery.

Working estimate: **roughly 2–4 engineering days**, plus external waits and the
24–48-hour soak. These estimates remain conditional on final CI and acceptance
findings. Implementing rootless clusters is outside the agreed 0.1.0 scope.
V05 dependency review is complete for the current lockfile with dated exceptions.
Optional refactors and explicitly deferred features are not new release blockers.
Fresh pre-release clusters, foreground-only native processes and the managed
Linux VM for macOS containers remain the agreed release scope.
