# 0.2.2: UX patch

0.2.2 is the UX release from the 10 October audit ([#674](https://github.com/reliaburger/reliaburger/issues/674)). It covers the CLI review, Kubernetes fidelity, chaos for jobs, demos, book and design-doc corrections and doc snippet tests, plus the follow-ups we filed while building 0.2.1. Every issue body is self-contained: why, decisions, findings with evidence, tests to write first, docs and done-when. This plan only fixes the order and the shared rules.

## The train

- **Branch:** `release-0-2-2`, cut from the tip of `release-0-2-1` on 16 October 2026, while 0.2.1 was still being qualified.
- **Gate PR:** a draft into `release-0-2-1`, so its diff shows only 0.2.2. It retargets to `main` once 0.2.1 has merged. It carries a `Fixes #N` line for every issue here, because closing keywords only fire on merge into `main`.
- **Each issue is one PR into `release-0-2-2`.** Whenever `release-0-2-1` moves, it's merged into the train, never rebased.
- **Version:** the crate stays at whatever `release-0-2-1` has until 0.2.1 ships. README and site labels compare the build version with the installer's release, so a premature `0.2.2-dev` fails their tests.
- **Compatibility:** `CURRENT` goes to 53/70 when the train opens. That's one bump for the whole release, because #704 changes the routed-fault messages. A later 0.2.2 PR that changes the wire or durable state adds a line under the 0.2.2 heading in `src/compatibility.rs` and never bumps again. 0.2.1 to 0.2.2 needs a fresh cluster.
