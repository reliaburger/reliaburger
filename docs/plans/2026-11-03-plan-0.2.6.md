# 0.2.6: The rest of the evaluation's bugs, and setup over SSH

0.2.6 is a patch release. It finishes the two fixes 0.2.5 shipped in part, adds `relish setup --ssh` for clusters on Linux machines you already have, makes the two maintainer-only test targets runnable by anyone and by CI, and clears the known flakes. Planned on 3 November 2026, after 0.2.5's promotion.

## After the tag

0.2.5's 12-hour memory run ([#1417](https://github.com/reliaburger/reliaburger/issues/1417)) runs on the published 0.2.5 before 0.2.6's gate, with the Mac charged and cool: 0.2.5's final ran during host thermal emergencies ([closure](../qualification/2026-11-03-v0.2.5-release-closure.md#a-quarter-of-the-job-throughput)), and the memory run also shows whether the job rate comes back. 0.2.6 makes no sustained-rate claim, so it owes no day run.

## Shared rules

- **Compatibility:** `main` is at 56/73, as 0.2.5 shipped. #1477 bumps `CURRENT` once, to 57/74; any later format change adds a line under the 0.2.6 heading in `src/compatibility.rs`.
- **Docs:** each PR updates its book chapter, and the manual or design doc where they describe the behaviour, in the same change. `--ssh` gets the Linux servers guide, manual chapter 00 and book chapter 15.
- **Tests:** `make ci` plus the gated target that matches what the PR touches.
- **Hosts:** the Mac Studio arrives on 4 November and takes builds and code work. The gate stays on the MacBook Pro, so 0.2.6's numbers compare with 0.2.5's, and it starts only when the Mac is charged and cool.

## The gate

#1477 moves `CURRENT` and #1500 touches the agent loop, so 0.2.6 needs the full gate. `release_tier.py` confirms it at freeze ([a gate scaled to the release](../releasing.md#a-gate-scaled-to-the-release)). Target: freeze on Thursday 5 November, gate that night and Friday's final, ready to tag on Saturday 7 or Monday 9 November. Only the maintainer tags and promotes.

## Done when

Every issue above is closed by a merged PR or moved by a recorded decision, the gate passes on a candidate built from `main`, and 0.2.6 is promoted.
