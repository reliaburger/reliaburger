# Known flakes

CI runs with `retries = 0` (`.config/nextest.toml`). A test that fails and then
passes on one re-run is a flake, and it goes in this register the same day,
with its cause. If the cause isn't fixed that day, open an issue in the next
patch milestone and link it from the row. Remove a row only when the fix has
landed and a loop that used to fail passes.

Rows up to 29 September 2026 come from the pre-0.1.0 checklist
([frozen copy](plans/archive/progress-to-0.1.0.md#known-flakes)).
